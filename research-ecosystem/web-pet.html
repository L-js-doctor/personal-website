Web Pet Research Companion

A future website companion that turns research actions into visible feedback. The first concept is a small cat that reacts to literature search, paper intake, deep-reading generation, export, and errors.

Core Idea

The pet should not be decoration only. It should make the research workflow easier to understand: every input, processing step, and output gets a small visible action.

Action Map

  1. PubMed search: the cat looks through a magnifying glass and waits for papers.
  2. Add paper to queue: a paper card slides toward the cat, and the cat carries it away.
  3. Manual AI prompt: the cat stamps the paper as ready for ChatGPT/Codex.
  4. AI deep read: the cat eats the paper, pauses to think, then starts writing.
  5. Generate artifact: the cat writes a note and pushes it toward the output box.
  6. Download/export: the cat files the note into a folder.
  7. Error or missing endpoint: the cat shows a question mark and points to the setup checklist.

Build Phases

  1. Phase A: CSS-only companion in the lower-right corner with idle, thinking, writing, done, and confused states.
  2. Phase B: connect state changes to Literature Lab buttons and PubMed events.
  3. Phase C: add paper movement, small speech bubbles, and accessible reduced-motion behavior.
  4. Phase D: make the companion context-aware, suggesting missing fields, next reading steps, and export options.

Design Rules

  • It must never block reading or cover important text.
  • It must work without AI or Vercel.
  • It should react to real actions rather than looping random animations.
  • It needs a quiet mode for focused reading.
  • It should explain setup problems in friendly language.

First Implementable Version

Start with a lightweight companion on Literature Lab only. The first version can be built with HTML, CSS, and small JavaScript state changes. Later, it can become a richer animated character.
