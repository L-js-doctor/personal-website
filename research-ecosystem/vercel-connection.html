Vercel Connection Checklist

This is the practical handoff checklist for connecting the research website to a real AI backend. The code is already prepared; this page records the account-level steps that must be completed in Vercel.

What Success Looks Like

  1. Vercel imports the GitHub repository L-js-doctor/personal-website.
  2. The deployed project includes api/deep-read.js.
  3. Vercel environment variables include OPENAI_API_KEY.
  4. The endpoint https://your-vercel-project.vercel.app/api/deep-read returns ok: true.
  5. The Literature Lab Test endpoint button reports that the endpoint is online.
  6. The Literature Lab AI deep read button returns a structured paper reading note.

Dashboard Steps

  1. Open Vercel and sign in with GitHub.
  2. Create a new project and choose L-js-doctor/personal-website.
  3. Keep the default framework setting unless Vercel detects a static project automatically.
  4. Before or after first deploy, open Project Settings, then Environment Variables.
  5. Add OPENAI_API_KEY with the real key from your OpenAI account.
  6. Optional: add OPENAI_MODEL with gpt-5.4.
  7. Optional but recommended: add ALLOWED_ORIGIN with https://l-js-doctor.github.io.
  8. Redeploy after adding environment variables.

Website Test Steps

  1. Copy the deployed API URL, ending in /api/deep-read.
  2. Open Literature Lab.
  3. Paste the URL into AI endpoint URL.
  4. Click Save endpoint.
  5. Click Test endpoint.
  6. If it says OPENAI_API_KEY is configured, paste a paper abstract and click AI deep read.

Command Line Test

After Vercel deploys, this PowerShell check should report endpoint health:

powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\test-ai-endpoint.ps1 -Endpoint https://your-vercel-project.vercel.app/api/deep-read

To send a real sample request, add -PostSample. That test uses OpenAI credits.

If Something Fails

  1. 404: Vercel did not deploy api/deep-read.js or the endpoint URL is wrong.
  2. OPENAI_API_KEY missing: add the environment variable in Vercel and redeploy.
  3. Origin is not allowed: check that ALLOWED_ORIGIN matches the website origin exactly.
  4. OpenAI request failed: check the API key, billing, model name, and Vercel function logs.
