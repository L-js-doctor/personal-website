AI Handoff Lab

This page records how to hand the website to another GPT, Codex session, or developer without losing context. It turns the project package into a repeatable workflow: summarize, attach source, state constraints, validate, and continue from the current research ecosystem.

After any change, run the site validator and confirm GitHub Pages or the chosen host still publishes.

Current Package Contents

  • `PROJECT_HANDOFF.md` - project goal, architecture, completed modules, and deployment path.
  • `GPT_CONTINUE_PROMPT.md` - a ready-to-copy prompt for another GPT or Codex agent.
  • `FILE_MANIFEST.md` - core source files and research data map.
  • `VALIDATION.md` - validation command, expected result, and manual checks.
  • `source/` - clean website source snapshot without `.git` or local upload tooling.
