GitHub Lab

GitHub Website Ecosystem Lab

This page explains how the research website is using GitHub as an ecosystem, not just as file storage. Each layer is tied to a real file or workflow in this repository.

Layer 1

GitHub Pages

GitHub Pages publishes the static website from the repository. The public site is the reading surface; the repository is the editable source of truth.

Current evidence: `personal-website` publishes to `https://l-js-doctor.github.io/personal-website/`.

Layer 2

Repository-backed data

Research records live as JSON under `data/research/`. The website reads these files, and Codex can update them through commits. This keeps research data versioned and reviewable.

Current evidence: `literature.json`, `knowledge.json`, and `graph.json` power the research pages.

Layer 3

Issues as research requests

GitHub Issues can become structured requests: literature deep reading, data import, or future feature work. This turns a vague task into a trackable research workflow.

Current evidence: `.github/ISSUE_TEMPLATE/literature-deep-reading.md` and `research-data-import.md`.

Layer 4

Validation and quality control

A research website should not silently break. The local validator checks important pages, JSON files, PubMed hooks, graph hooks, and required links.

Current evidence: `tools/validate-site.ps1` runs before publishing.

Layer 5

Actions boundary

GitHub Actions can eventually run validation automatically, but publishing workflow files requires the `workflow` token scope. We intentionally do not enable that permission until you choose it.

Current evidence: the workflow is prepared locally, and the README documents the permission boundary.

How you will use this with Codex

  1. You ask for a paper search, deep reading, knowledge map, or project page.
  2. Codex creates or updates HTML and JSON files in the repository.
  3. The validator checks that core links and data still exist.
  4. Codex publishes the static site through GitHub Pages.
  5. The graph page shows how the new content connects to the existing ecosystem.
