Roadmap

科研生态建设路线图

这个网站会缓慢建设，不追求一步到位。每一阶段都让 GitHub 的一个能力变成你能实际使用的科研工作流。

Phase 1

可操作的静态科研门户

用 GitHub Pages 发布首页和各资料目录；每个科研模块先具备本地新增、搜索、删除、导出能力。

Phase 2

内容库与索引

把 PubMed 检索结果、本地记录和整理后的 JSON/HTML 提交到 GitHub 仓库，形成可版本管理的文献库、知识库和日志库。

Phase 3

GitHub 协作层

用 Issues 管问题、文献精读请求和数据导入；用 Projects 管长期计划；用 Pull Requests 审核重要改动。

Phase 4

自动化发布

引入 GitHub Actions 或静态站点生成器，让 Markdown、数据表和笔记自动变成网站页面。

Phase 5

科研作品集

形成可公开展示的研究主题页、综述页、图表页、工具页和项目成果页。

Future

网页宠物研究伙伴

设计一只与文献工作流互动的小猫：搜索文献时观察，加入精读时叼走纸张，AI 精读时吃下论文并写笔记，导出时整理成文件夹。先做轻量版，再逐步接入动画和上下文提醒。
